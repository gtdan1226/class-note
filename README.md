# 클래스 노트

김도훈 선생님과 함께하는 레슨/연습 기록

기타, 작곡 등 실용음악 레슨을 진행하는 선생님이 학생별 계정을 만들고, 학생은 자신의 목표와 연습 기록을 남기는 웹 기반 MVP입니다. 현재 버전은 로컬 저장소를 사용하므로 설치 없이 바로 실행할 수 있고, 이후 Supabase Auth와 DB로 옮기기 쉽게 화면과 데이터 구조를 나누어 두었습니다.

## 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 설치 없이 `index.html`을 직접 열어도 동작합니다.

## 데모 계정

- 선생님: `teacher` / `1234`
- 학생: `mina` / `1111`
- 학생: `jiwoo` / `2222`
- 보호자: `parent` / `3333`

로그인 화면의 `데모 초기화` 버튼으로 브라우저에 저장된 로컬 테스트 데이터를 기본 상태로 되돌릴 수 있습니다.

## 들어간 기능

- 선생님 관리자 로그인
- 학생별 계정/비밀번호 생성 및 관리
- 보호자 계정 생성 및 학생 매칭 관리
- 보호자 읽기 전용 기록 열람
- 연간, 월간, 주간 목표 등록과 달성 체크
- 학교 시간표 형태의 주간 시간 단위 일정표
- 연습 결과 사진 업로드, 클라우드 자료 링크, 목표 달성 여부 기록
- 레슨 내용, 과제, 과제 피드백 작성
- 레슨 회차별 날짜 타임라인
- 대시보드 과제 노출 및 완료 체크
- 일주일 연습일지, 스케줄 성과, 자기 피드백, 선생님 피드백 정리
- 모바일과 데스크톱 반응형 레이아웃

## Supabase 전환 메모

`supabase/schema.sql`에 기본 테이블 설계를 넣었습니다. 실제 배포 버전에서는 현재의 데모 비밀번호 저장 방식을 제거하고 Supabase Auth를 사용해야 합니다.

권장 흐름:

1. Supabase 프로젝트 생성
2. `supabase/schema.sql` 실행
3. `practice-results` Storage bucket 생성
4. 학생 계정은 Supabase Auth 사용자로 초대 또는 생성
5. 클라이언트에서 localStorage 대신 Supabase query로 교체
6. Vercel 환경 변수에 Supabase URL과 anon key 등록

## Vercel 배포 메모

정적 웹앱이므로 프로젝트 루트를 이 폴더로 잡아 배포하면 됩니다. Framework Preset은 `Other`, Build Command는 비워두고 Output Directory는 `.`로 둘 수 있습니다.
